# Classic Fireplace — Striven / Shopify Bridge

Google Apps Script project for Classic Fireplace's Striven and Shopify workflows.

Price bridge repairs are maintained on the `fix/price-bridge` branch. The repair files replace the same named files in the existing Apps Script project; they are not a standalone project. Changes are reviewed and tested before live deployment.

Do not store API tokens, client secrets, or private report URLs in this public repository. Configure them in Apps Script Properties.
